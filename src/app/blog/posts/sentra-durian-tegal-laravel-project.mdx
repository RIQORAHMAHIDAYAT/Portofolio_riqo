## Background

As part of a university community service program (Pengabdian Pada Masyarakat), my team and I were given the opportunity to help digitize **Sentra Durian Tegal** — a local agricultural SME specializing in premium durian and botanical saplings.

Their core problem: a non-strategic physical location and 100% offline marketing. No digital presence whatsoever.

## The Core Challenge

The biggest challenge wasn't technical — it was the **digital literacy gap**. Any system we built had to be independently operated by an SME owner with no IT background.

Our architecture focused heavily on:
- UI simplicity for the admin panel
- Clear feedback loops when errors occur
- Solid security without added complexity

## Tech Stack

- **Laravel** — PHP MVC framework for clean routing, secure server-side logic, and Blade templating
- **MySQL** — Relational schemas for product metadata, admin authentication, and analytics log storage
- **Google Search Console** — Production indexing to ensure discoverability on Google Search
- **Production Hosting** — DNS configuration, server environment setup, and commercial domain provisioning

## Features Built

![Sentra Durian Tegal Admin Dashboard](/images/projects/project-02/image5.png)

We built four core pillars:

1. **Dynamic Product Catalog** — Structured showcase for premium durian varieties and botanical saplings, with descriptions, tiered pricing, and real-time availability tags
2. **Centralized Admin Panel** — Backend dashboard empowering the owner to manage gallery assets, inventory, and customer testimonials
3. **Traffic & Visitor Analytics** — Internal analytics module tracking daily/weekly/monthly metrics: IP logs, timestamps, user-agents, and page visit patterns
4. **Direct Messaging Integration** — Structured feedback forms routing digital traffic into interactive sales channels

## Results & Impact

![Product Handover to Sentra Durian Tegal SME](/images/projects/project-02/image3.png)

The web profile successfully established a solid digital identity for Sentra Durian Tegal, breaking their geographic isolation and scaling visibility to a wider regional audience. The platform indexed live on Google Search for target local keywords.

Most rewarding of all: through hands-on technical training sessions, we fully transferred system ownership to the client. They can now independently update their digital storefront.

![Handover Ceremony and Training Session](/images/projects/project-02/image4.png)

This project taught me that **the best solution isn't the most sophisticated one — it's the one your users can actually use**.
