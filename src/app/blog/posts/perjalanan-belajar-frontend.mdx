## How It Started

I started learning front-end development in my second semester of Informatics Engineering. Honestly, I had no real expectations — I was just curious about why some websites felt *pleasant* to use, while others felt exhausting.

That simple question is what eventually changed the focus of my coding journey.

## Mistakes That Made Me Grow

### 1. Jumping Into Frameworks Too Fast

In my first week, I jumped straight into React tutorials. The result? Complete confusion. I didn't understand why "state" was needed, why props mattered, or why JSX felt so strange.

Lesson learned: **Get a solid understanding of HTML, CSS, and vanilla JS first**. Frameworks just structure those patterns more cleanly — if your fundamentals aren't strong, frameworks make things worse.

### 2. Writing CSS Without a System

My early CSS was full of random classes like `.box-blue-2`, `.container-left-top`, `.red-button`. A month later, I couldn't even read my own code.

Now I always start a project by defining a **design system** — color tokens, spacing scale, typography scale — before writing a single component.

### 3. Ignoring Accessibility

Early on, I thought accessibility was only for government or enterprise websites. I was completely wrong.

Accessibility isn't just about screen readers — it's about **whether everyone can use your website comfortably**, including people who only use a keyboard, or those with a slow internet connection.

## Tools I Use Now

- **Figma** — to design and validate layouts before coding
- **Flutter** — for cross-platform mobile UI
- **Next.js** — for web apps that need SSR and high performance
- **Laravel** — for projects that need a solid PHP backend

## The Most Valuable Lesson

After two years, the most valuable lesson I've learned is this:

> **The best code is the code that's easiest for others to understand — or for yourself, six months from now.**

Performance matters. Aesthetics matter. But maintainability is the most overlooked, and most often the root cause of future problems.

## What's Next

I'm currently deepening my knowledge of:
- **TypeScript** for better type safety
- **Web Performance** — Core Web Vitals and loading optimization
- **Design Systems** — how to build scalable, consistent component libraries

If you're just starting out with front-end development: don't rush. Master the fundamentals, build real projects, and don't be afraid to make mistakes. Mistakes are where the most effective learning happens.
