## Overview

Development of CekKomposisi, a mobile application that analyzes food and beverage packaging to detect and display nutritional composition. The UI was designed in Figma and implemented using Flutter for the front-end, connected to a Flask-based web server with a MySQL database.

## Key Features

- **Food packaging Detection**: Implemented ented image-based detection to identify packged food and beverage products and match them with nutritional data stored in a MYSQL database.
- **Mobile UI Development (Flutter)**: Built responsive and user-friendly mobile interface in Flutter based on Figma design, focusing on clear visualiaton of sugar, salt, and fat consumtion data.
- **Backend Integration (Flask API)**:  Integrated the Flutter front-end with RESTful APIs developed using Flask, enabling real-time communication between the mobile app and the backend server.
- **Data Visualization**: Developed interactive charts and progress indicators to help users monitor daily and weekly nutritional intake effectively.
- **Database Management (MySQL)**: Structured and optimized product and nutrition data in MySQL to ensure efficient queries and accurate product-data mapping.

## Technologies Used

- **Flutter**: Cross-platform mobile application development  
- **Figma**: UI/UX design and prototyping  
- **Flask**: REST API and backend development  
- **MySQL**: Relational database management  

## Challenges and Learnings

One of the main challenges was ensuring accurate detection of food packaging images and correctly matching them with existing database records. Variations in packaging design, lighting conditions, and image quality often reduced detection reliability.

To address this, improvements were made in API handling, database structuring, and image preprocessing strategies to enhance matching accuracy. This project strengthened my understanding of full-stack integration and data consistency between Flutter, Flask, and MySQL.

## Outcome

CekKomposisi successfully delivers a functional mobile solution that helps users understand nutritional content from packaged products. The project improved development workflow through structured UI implementation from Figma and solid backend integration. It serves as a scalable foundation for future enhancements in image detection accuracy and system performance.
