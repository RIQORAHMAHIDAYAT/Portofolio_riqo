## Overview

**Harkat Racing 3D** is a 3D arcade racing game developed with Unity 6 and the Universal Render Pipeline (URP). Take control of a car or motorcycle, master drift mechanics, collect power-ups, and compete across multiple tracks to achieve the best lap times. The game features three input modes — keyboard, gamepad, and mobile touch — with a real-time minimap and race countdown system.

## Key Features

- **Dual Vehicle System** — Car with WheelCollider physics & drift mechanics; Motorcycle with Rigidbody-based physics & lean system
- **Drift Mechanics** — Dynamic rear-wheel friction reduction based on speed and steering input
- **Power-ups** — Speed boosters & collectible coins scattered across tracks
- **Multi-Lap Racing** — Configurable lap count with finish line detection
- **Three Control Modes** — Keyboard, Gamepad, and Mobile Touch (switchable in-game)
- **Real-time Minimap** — Top-down track navigation with vehicle heading indicator
- **Race Countdown** — 3-2-1-GO! start sequence
- **Auto-Respawn** — Anti-stuck detection and automatic vehicle respawn
- **Runtime UI** — All HUD elements generated programmatically (no prefab dependencies)

## Challenges and Learnings

Building a dual-vehicle system with fundamentally different physics approaches (WheelCollider for the car vs Rigidbody for the motorcycle) was a significant architectural challenge. Each vehicle required its own controller logic while sharing common systems like input handling, power-up detection, and lap tracking.

The drift mechanics involved carefully tuning friction curves and angular velocity to create a responsive yet forgiving feel. Implementing three simultaneous control schemes (keyboard, gamepad, and touch) through a unified input abstraction layer required thoughtful design to avoid code duplication while maintaining responsiveness across all input types.
